# Repositorio de Soluciones - Maratones de Programación ICPC

Este repositorio general centraliza las soluciones a diversos ejercicios y problemas presentados en las **Maratones Nacionales de Programación** y eventos relacionados con la **ICPC** (International Collegiate Programming Contest).

El proyecto funciona como un archivo histórico y base de conocimiento: aloja soluciones de maratones desde el año **2023** en adelante, y **se seguirá actualizando** constantemente a medida que se resuelvan nuevos problemas y se participe en futuras competencias.

## Lenguajes de Programación

Los algoritmos y soluciones de este repositorio se abordan utilizando múltiples enfoques y herramientas, incluyendo principalmente:
- **C++**: Utilizado para las competencias que requieren la máxima eficiencia, control de memoria y ejecución rápida, aprovechando la Standard Template Library (STL).
- **Python**: Utilizado por su versatilidad para implementaciones rápidas, scripts de prueba, y manejo eficiente de grandes números o estructuras de datos complejas.

## Estructura del Repositorio

El repositorio se organiza en carpetas según la edición de la competencia y sus fases. Como cada fase tiene su calentamiento llamado warmup se divide una subcarpeta para darle solución a cada uno de estos ejercicios planteados.
