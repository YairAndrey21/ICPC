# Maratón Nacional de Programación 2023 - Ejercicios de Warmup

Este repositorio contiene las soluciones a los ejercicios correspondientes a la **Maratón Nacional de Programación 2023**. 

Esta competencia pone a prueba la lógica, el análisis matemático y las habilidades de resolución de problemas mediante algoritmos eficientes en C++. A continuación, se detalla la estructura de este directorio y los problemas abordados.

## Ejercicios Resueltos

1. **[Idoneal](./Idoneal)**: Problema basado en teoría de números y ecuaciones diofánticas, donde se busca si un número puede expresarse bajo una suma de productos específicos.
2. **[ShufflingRobot](./ShufflingRobot)**: Problema que involucra permutaciones, grafos y el cálculo del mínimo común múltiplo (MCM/LCM) para predecir el comportamiento cíclico de un robot que mezcla cartas o elementos.
3. **[Water Drainage](./Water%20Drainage)**: Problema "Ad-Hoc" de análisis de arreglos para detectar pozos o depresiones locales en un perfil de elevaciones topográficas.

Cada carpeta contiene el código fuente en C++ (`.cpp`), archivos del proyecto (Code::Blocks) y un archivo `README.md` específico con la explicación detallada de la solución, así como los temas y conceptos abordados.
